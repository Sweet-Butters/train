# train

KTX 이동 중 Cursor 모바일로 개발하는 프로젝트.

## 개발 환경

- **08:55~10:45 (KTX 이동 중)**: Cursor 모바일에서만 작업
- **13:00~ (강릉 도착 후)**: 데스크탑에서 `git pull` 받아 이어서 작업

## 모바일 작업 규칙

1. 기능 단위로 자주 커밋한다.
2. 터널 진입 전에 push한다.
3. push가 실패하면 로컬 커밋만 쌓아두고, 연결이 복구되면 한 번에 push한다.
4. **하차 전(10:45~11:00)에 반드시 마지막 커밋 + push를 끝낸다.**
   push하지 않은 작업은 데스크탑에서 이어받을 수 없다.

## 하차 전 체크리스트

- [ ] 모든 변경사항 커밋 완료
- [ ] push 완료
- [ ] GitHub 웹에서 최신 커밋이 보이는지 눈으로 확인
